## What's Changed

### Shell Alias Support (`tcsh`, `csh`, POSIX `sh`) & Safe Shell Detection
- Added `tcsh`, `csh`, and `sh` (`dash`/`ash`/`ksh`) to `bitefoundry-obsidian alias` (`install`, `uninstall`, `status`, `snippet`/`init`).
- Normalized `$SHELL` detection by basename (stripping login `-` prefixes and `.exe`) with explicit errors on unsupported shells instead of silently modifying `~/.bashrc`.
- Preserved existing `~/.cshrc` for `tcsh` users when `~/.tcshrc` is absent, and preserved symlinked RC files.

### Compact Read Frontmatter Surfacing & Selective `fields` Projection
- `read_note` (`compact: true`) now lists actual sorted `omitted.frontmatter_keys` alongside omitted counts instead of a bare `"frontmatter"` string.
- `read_note` (`compact: false`) now includes `is_bookmarked`, `size_bytes`, `images`, and `md_links`.
- Added selective `fields: [...]` projection to `read_note` (supporting `frontmatter`, `frontmatter.<key>`, `tasks`, `backlinks`, `outgoing_links`, `images`, `md_links`, `is_bookmarked`, `size_bytes`, `body`, `raw_markdown`, plus `missing_fields`) without reading full note bodies when only metadata is requested.

### Symlinked `$HOME` & npm Postinstall Hardening
- Fixed `scripts/postinstall.mjs` main-module detection via `fs.realpathSync` so native binary linking runs reliably when `$HOME` or the npm prefix is a symlink.
- Watched `canonical_root` in `register_native_watcher` so vaults under a symlinked `$HOME` watch reliably while inner vault symlinks remain blocked.
- Preserved dotfile symlinks in `write_atomic` (while refusing `0600` secret symlinks), expanded `~/` on `OBSIDIAN_CONFIG_DIR`/`OBSIDIAN_DATA_DIR`/`$EDITOR`, and resolved symlinked binaries in `updater.rs`.
