## What's Changed

### Obsidian Live Preview Direct Canvas Editing
- Upgraded `InlineNoteEditor` to **Live Preview** mode by default (`EditorMode::LivePreview`, toggleable with `Ctrl+M` or the `[Live]`/`[Src]` header pill): inactive lines render styled Markdown (headings, bold/italic/code/strike/highlight, `[[wikilinks]]`, `#tags`, `☐`/`☑` tasks, callout bars, code fences, and frontmatter) while the active cursor line reveals raw syntax-highlighted Markdown with exact ASCII + Korean/CJK hardware cursor tracking.
- Clicking any rendered note line or empty canvas row opens Live Preview directly at the clicked position without needing to press `e` first (preserving direct clicks on checkboxes, wikilinks, image previews, HTML cards, and header pills).

### Native-Terminal Lock-Free TUI Input
- Replaced `crossterm::event::EventStream` with a dedicated lock-free `TerminalEventReader` (OS reader thread + Tokio `mpsc::unbounded_channel`) and wrapped terminal output in a 64 KiB `BufWriter<Stdout>` with queued synchronized updates and clean reader pause/resume around `$EDITOR` and Windows `Resize` VT probing.
