Note reads return compact JSON by default, including omission counts, a full-read hint, and the modification time. Use `bitefoundry-obsidian notes read <note> --json --full` or MCP `read_note` with `compact: false` for expanded detail.

Moving a note preserves the destinations of its relative Markdown links and image embeds. An ambiguous short name lists its candidates, so reads and writes can be directed to the intended vault-relative path.

Task and note lists default to 50 entries in JSON and MCP. Follow the returned cursor for subsequent entries. Graph results distinguish ambiguous, missing and attachment targets and report the applied depth.
