## What's Changed

### WYSIWYG Rendered Default Editing & 3-Mode Toggle (`Ctrl+M`)
- Added full WYSIWYG **Rendered** editing (`EditorMode::Rendered`, pill `[Render]`) as the new default mode: even the active cursor line stays rendered (headings, checkboxes, bullets, quotes, bold/italic/code/strike/highlight, `[[wikilinks]]`, `#tags`) with exact ASCII + Korean/CJK hardware cursor projection.
- Added `Ctrl+M` / clickable header pill cycling across **`[Render]` → `[Live]` → `[Src]`** so users can edit cleanly while rendered or inspect raw Markdown syntax at any time.
- Added WYSIWYG cursor ergonomics in `[Render]` mode: `←`/`→` skip hidden Markdown delimiters cleanly, `Home` snaps to visible content start, `Backspace` at content start unwraps block prefixes (`## `, `- [ ] `, `- `, `> `) in one undoable edit, and deleting inline content cleans up empty orphan delimiter pairs (`****`, `~~~~`, `` `` ``, `[[]]`).

### Visibility & Parser Fixes on `Esc`
- Fixed `Esc` exit scrolling so edited blocks remain visible in `note_view` (including tall blocks), defaulted editor entry cursor to the first body line after YAML frontmatter, added fallback rendering for freeform/invalid frontmatter text, preserved continuation paragraphs after nested lists/code blocks in `vault/parser.rs`, and kept bare `#` heading markers visible on inactive lines.
