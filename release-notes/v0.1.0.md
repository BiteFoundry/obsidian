# `@bitefoundry/obsidian` v0.1.0

Initial standalone release of `@bitefoundry/obsidian` (`obsidian` / `obs`) — an Obsidian-native terminal workspace, interactive Braille knowledge graph, local HTTP JSON API (`:8792`), and 18-tool stdio MCP server.

## Highlights

- **Zero-Auth Native Vault Auto-Discovery**: Automatically reads Obsidian's native `obsidian.json` across Windows, macOS, and Linux, plus supports `--vault`, `OBSIDIAN_VAULT`, `obsidian vaults add|list|use|remove`, and `obsidian init <dir>`.
- **Direct Obsidian Markdown Engine**: Native YAML frontmatter, shortest-path case-insensitive `[[wikilinks]]` + alias resolution, `![[embeds]]`, `#nested/tags`, collapsible Obsidian callouts (`> [!tip]-`), headings outline, atomic writes, surgical checkbox toggles, `.trash/` safe deletion, and Daily Notes (`.obsidian/daily-notes.json`).
- **SQLite WAL + FTS5 Knowledge Graph Index**: Incremental `mtime_ms` + `size_bytes` scanner with instant backlinks, outgoing/unresolved links, orphans, local/global BFS graphs, and automatic `<3`-char Korean/CJK `LIKE` fallback.
- **Signature Obsidian-Native 3-Pane TUI**: Iconic Obsidian purple (`#a78bfa` / `#7c3aed`) Minimal-Chrome workspace with 5-tab sidebar (`Files`, `Tags`, `Bookmarks`, `Outline`, `Tasks`), live interactive Note Canvas, **Interactive Braille Knowledge Graph View (`G`)**, Right Backlinks Inspector (`B`), Quick Switcher (`Ctrl+O`), Vault Switcher (`Ctrl+S`), Link Extractor (`u`), File Picker with `zoxide` (`Ctrl+F`), HD image previews (`v`), and 5 curated palettes (`Obsidian Dark`, `Catppuccin Mocha`, `Tokyo Night`, `Nord`, `Warm Paper`).
- **4-in-1 Agent Interface**: Single native Rust binary powering TUI, `--json` CLI, background watcher IPC daemon, HTTP API (`:8792`), and 18-tool stdio MCP server across 6 prebuilt npm platforms (`win32/darwin/linux` × `x64/arm64`, GLIBC 2.28, macOS 11.0).
