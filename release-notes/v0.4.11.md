## What's Changed

### Performance Optimization Suite (SQLite/Trigram, SoA Graph, Parallel Vault Scan & Pixel Pipeline)
- **SQLite/FTS5 & Async Server**: Added a 4-reader WAL pool + tuned PRAGMAs + `prepare_cached`, migrated `notes_fts` to `trigram` + `rowid`-indexed deletes (`O(N²) → O(log N)`), pushed SQL filtering/pagination into `list_notes_page`, streamed `vault_index_fingerprint` directly into SHA-256, and offloaded `serve.rs` storage/sync onto `spawn_blocking` with per-vault singleflight coalescing.
- **Parallel Vault Scan & Parser**: Parallelized read + SHA-256 + Markdown parse via `std::thread::scope`, reused `entry.metadata()` and zero-alloc sorting in `vault/fs.rs`, and added `Cow::Borrowed` / byte-scan fast paths in `vault/parser.rs`.
- **TUI, Graph & Pixel Engine**: Replaced O(N²) `HashMap<String>` graph layout with flat SoA `Vec<f64>` + uniform spatial grid, removed duplicate per-frame inline-editor layout, added sidebar/note/editor caches, fixed 2-pass `html_preview` cache thrashing, coalesced mouse moves and deferred pixel payloads in `tui.rs`, fixed double CLI SVG rasterization, upgraded Sixel to flat 32K histogram + 5-5-5 LUT + 2-row `i16` dithering + Fast PNG, and enabled `opt-level = 3` for codec/parser crates.
