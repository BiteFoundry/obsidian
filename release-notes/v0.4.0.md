## Changes

Moved notes keep their relative attachment links. Creating a note preserves existing frontmatter and reports tag conflicts. Local graph output distinguishes missing and ambiguous note targets.

## Compatibility

- After `daily --append ... --json`, read `rel_path`, `created`, and `appended` from the response. Add `--full` to the original append command if it also needs to return the note. In MCP, use `read_note` with the path returned by `daily_note` to read the result without appending twice.
- Runtime failures with `--json` exit with status 1 and write one JSON object to stdout with `error.code` and `error.message`. Argument parsing errors use stderr and exit with status 2.
- Moving a note to a destination outside the vault or outside the set of indexed Markdown paths now returns `invalid_destination`. Choose an indexed path inside the vault.
