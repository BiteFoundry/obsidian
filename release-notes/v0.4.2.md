## Changes

This release adds opt-in short shell alias management (`ob` -> `bitefoundry-obsidian`) and container / MCP registry packaging for Glama and the Official MCP Registry.

### Added

- **Shell alias management (`bitefoundry-obsidian alias`)**:
  - `bitefoundry-obsidian alias install` writes a guarded, idempotent alias block (`ob` -> `bitefoundry-obsidian` by default, customizable via `--name`) to PowerShell, zsh, bash, or fish profiles with automatic PATH collision checks, `--dry-run`, `--force`, and `--json`.
  - `bitefoundry-obsidian alias status`, `alias uninstall`, and `alias snippet` (`alias init`) inspect, remove, or print the shell snippet directly.
- **Container & MCP Registry packaging**:
  - Added `Dockerfile`, `.dockerignore`, and `.github/workflows/docker.yml` to publish multi-arch (`linux/amd64`, `linux/arm64`) images to `ghcr.io/bitefoundry/obsidian`.
  - Added `glama.json`, `server.json`, and `mcpName` (`io.github.BiteFoundry/obsidian`) for Glama and Official MCP Registry distribution.
