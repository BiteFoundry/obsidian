Open and edit notes whose names contain a hash, a literal percent sign or a leading hyphen. On Windows, changing only the capitalization of a note name also updates its filename.

Wikilinks and local Markdown links resolve consistently across backlinks, graph views and note moves. Links and tags inside formatted text and tables are indexed, while code spans keep their literal content.

Task toggles change just the checkbox character and preserve surrounding file bytes. Vault selection reports unknown or conflicting names and identifies a daemon already running for another vault.
