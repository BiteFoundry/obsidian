## What's Changed

### Startup & Incremental Vault Indexing
- Eliminated blocking startup scans and duplicate double-scans in both TUI (`run_tui`) and daemon (`run_daemon_foreground`) by hydrating frame 1 immediately from SQLite and running a single background reconciliation scan via the live watcher.
- Added `VaultLinkIndex` to replace `O(links × notes)` linear link/alias scans with indexed resolution across sync, detail loading, outgoing links, and Knowledge Graph construction.
- Released the SQLite `Mutex<Connection>` during disk reads, SHA-256 hashing, and Markdown parsing in `sync_vault_with_options`, added a zero-change fast path, and switched note upserts/deletes to `prepare_cached`.

### Single-Note Write & UI Thread Responsiveness
- Replaced redundant full-vault `sync_vault` rescans with path-scoped `sync_paths` across 15+ single-note write paths in `storage`, `tui`, `ui/app`, `cli`, `mcp`, and `serve`.
- Deferred Knowledge Graph rebuilds until `CanvasMode::Graph` is active, eliminated unnecessary HTML directory walks on Markdown-only saves and bookmark toggles, delegated `RefreshAll`/`SwitchVault` asynchronously to the live watcher, and suppressed self-write watcher echo reloads while preserving cross-process detection.

### Test Hardening
- Guarded unit-test config and draft persistence from mutating the host user config directory (`#[cfg(test)]`).
