## What's Changed

### Centered ↔ Full Layout Parity & Width-Aware Text Wrapping
- Fixed text clipping across Centered and Full reading widths in `note_view`, `inspector`, and `sidebar` by migrating notes, tables, callouts, code blocks, and frontmatter to display-width-aware styled span wrapping (`wrap_styled_spans` / `render_wrapped_table`).

### Unified `pulldown-cmark` Vault Markdown Parser
- Replaced the ad-hoc line-based Markdown parser in `src/vault/parser.rs` with `pulldown-cmark 0.13` (preserving Obsidian wikilinks, embeds, tags, callouts, frontmatter, and math/task blocks) and unified `.md` preview rendering on `bitefoundry-html::markdown`.

### Terminal Image Preview Quality & Protocol Detection
- Replaced fixed low-resolution downsampling and distorted aspect-ratio math with terminal cell-geometry sizing and unified protocol detection across Kitty, iTerm2, Sixel, and half-block renderers.

### Native HTML/SVG/Canvas & Embedded Graphics Rendering
- Eliminated raw HTML/SVG/script source leaks in HTML/canvas previews via pure-Rust `bitefoundry-html` (`resvg 0.50` + `tiny-skia` + `base64`) for inline `<svg>`, `<canvas>`, and `data:image/*` graphics, with an explicit `[o: Browser]` banner for external `<script src>` content.

### TUI Modal Isolation, Mouse Scroll & Alias Sync
- Isolated modal backdrops and key routing, fixed right-click and inspector scroll interactions, and hardened alias/sync state handling.
