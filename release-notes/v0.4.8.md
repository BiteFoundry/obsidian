## What's Changed

### Sidebar Tree Navigation, Tag Hierarchy & P0 Safety Fix
- **P0 Fix**: Scoped `ToggleSelectedTask` (`Space`/`x`) strictly by focus/tab so pressing `Space` on a folder in the Files sidebar toggles the folder instead of silently mutating checkboxes inside the open note file (and blocked task writes when focused on Inspector or Graph mode).
- Added standard `→` / `←` Files tree navigation (expand/enter first child/open note, collapse/jump to parent folder) alongside help hints.
- Updated Files folder counts to recursive subtree counts (`.md` + `.html`) and clamped tree indentation to stay readable in narrow sidebars.
- Built nested tag prefix aggregation in the Tags tab (de-duplicated per note) and synchronized Inspector Outline visibility with selection clamping.
